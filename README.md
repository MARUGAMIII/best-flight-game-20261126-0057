**Skyline Courier** — a bush-plane courier flight game for make.fun's "Make the Best Flight Game" bounty.

Fly a bush plane across the fictional Meranti Archipelago: thread glowing rings, land on island strips, and drop supplies on the beach. Vanilla JavaScript + Canvas 2D (voxel-space renderer, no dependencies, no network requests), with a full flight model — throttle, pitch and bank, stall, fuel, damage, gear and flaps — a lit instrument HUD (airspeed, altitude, vertical speed, heading tape, attitude indicator), and synth WebAudio sound.

## Missions

- **Ring Run** — fly 6 glowing rings in sequence, with time bonuses.
- **Island Hop** — land full-stop at Teluk Strip, then fly home to Meranti Field.
- **Supply Drop** — drop 3 crates onto Pasir Beach, scored by distance from the centre mark.

## Controls

- Arrow keys: pitch / bank
- W / S: throttle up / down
- F: flaps, G: gear, Space: action, Enter: start, R: restart, Esc: menu

Open `game/index.html` in desktop Chrome and fly. Screenshots in `screenshots/` are real renders of the game running in headless Chromium.
